# M4-R Batch 07 — Four original program-construction blueprints and human qualification cases

**Date:** 2026-10-16. **Class:** conceptual, **not ready-to-train workout prescriptions**, not an “optimal” program, not code. Each blueprint uses generic movement-action logic authored here, **not** a purchased Nippard week, spreadsheet, routine, set sequence or substitution list. All exercise examples are illustrative, and **no sets, reps, RIR, %1RM or guaranteed finish time is authorized**. Read [science decision queue](batch-07-science-standard-review-queue.md) first.

## Shared review methodology

A qualified reviewer should apply the same rubric to each independently constructed plan:

1. **User feasibility** — actual days, locally timed sessions, absolute/flexible cap, goals, available implements, technique readiness, substitutions, preferred movements and restrictions. Unknown input stays unknown.
2. **Intended movement diversity** — adequate chosen knee extension/flexion, hip extension, push/pull, shoulder and trunk actions where feasible; differentiate direct target and indirect synergists without a fixed half-set. Not every person or short session needs all actions.
3. **Stability versus variation** — at least a few comparable repeatable movement variants over repeated performed exposures; secondary choices vary only with a documented reason.
4. **Effort and progression honesty** — actual performed work, repetitions, loading basis, subjective RIR/RPE and recovery remain distinct; no invented baseline 1RM or automatic weekly improvement.
5. **Date integrity** — sessions follow selected actual dates across week/year/timezone boundaries. Missed work is not silently counted or reordered; preview is not activation.
6. **Bounded time** — account for warmup, setup, actual work, rest, movement transitions, equipment access and a safety margin. Hard 45 means **<=45 min when credibly feasible**, not estimated “close enough.”
7. **Safety/rights/consent** — don't overrule pain or missing competence; no clinical diagnosis. No copy of licensed-source sequences and no Authored-to-Customized conversion.
8. **Evidence honesty** — no claim of a universal winner, scientific set/RIR optimum or predicted muscle gain percentage. Record which elements are expert convention rather than directly tested superiority.

All cases are **pending independent coaching review**. They are not qualified because a Markdown file exists.

## Blueprint A — Two actual gym dates, *hard 45-minute* cap, hypertrophy priority

**Synthetic user constraints:** Tuesday and Saturday available, standard commercial gym equipment specifically confirmed, no special restrictions disclosed, high need for predictable session duration. Goal is broadly distributed hypertrophy with honest tradeoffs rather than maximizing every region in two short sessions.

| Exposure | Original action coverage and example feasible options (unordered archetypes) | Human issue to examine |
| --- | --- | --- |
| A | Knee-dominant leg work (machine squat/leg press); horizontal press (chest press); horizontal pull (supported row); knee-flexion isolation (leg curl); optional lateral-deltoid action | Whether compound overlap, warmups, 5 distinct setups, rest and availability fit a *real* 45-minute limit |
| B | Hip hinge/hip extension (dumbbell RDL or other safe fitted variant); unilateral knee-dominant leg movement; shoulder/scapular vertical pull (pulldown); shoulder press or another tolerated chest/shoulder action; optional calf/trunk work | Whether an additional action displaces an important priority; check technical fatigue from hinges and setup overhead |

**What is original here:** slots are chosen for functional coverage, not recreated from either Essentials PDF, with equipment/time as explicit constraints. No fixed exercise order/number of working sets from the source.

**Failure-case time rehearsal (synthetic, not measurement):** an estimated 8-minute preparatory block + 12-minute active repetitions/set preparation + 20-minute inter-set rests + 8-minute equipment changes/waits + 4-minute buffer = **52 minutes**, so **FAIL hard 45**. Program preview must offer user-chosen reductions/replacements, an extra date, or a longer cap. It must not silently announce success or claim an inferior-volume alternative gives identical results. Actual measured timing and independently approved set counts would be needed for a valid pass.

**Human verdict:** *Not yet qualified*; physiology, time estimation and chosen sets/effort require review.

## Blueprint B — Four fixed dates, 60-minute *flexible* cap, Upper/Lower preference

**Synthetic context:** Monday/Tuesday/Thursday/Saturday, access to barbell and cable/machines specifically confirmed, familiar with core movements, general hypertrophy goal with some strength interest.

| Session identity | Independent movement emphasis (not complete workout instructions) | Progression anchor |
| --- | --- | --- |
| Upper A | Stable horizontal press + horizontal pull; shoulder and elbow actions fill uncovered intended muscles | Keep one reproducible pressing variant and row setup, track actual movement/rep and effort |
| Lower A | Squat-dominant + knee-flexion + calf/trunk actions | Track squat-pattern load basis/ROM consistently |
| Upper B | Different press vector + vertical pull + rear/side deltoid + selected arm work if exposure and time permit | Hold the selected secondary vector stable long enough for comparisons |
| Lower B | Hinge/hip extension + unilateral quad action + posterior-chain accessory | Respect recovery/technique; do not assume existing 1RM is safe or current |

**Why two Upper and two Lower days are plausible:** organization distributes different actions across actual fixed dates; the **split name alone has no validated hypertrophy bonus**. Secondary shoulder/arm exposure from pressing and pulling is separately recorded, not assumed zero.

**Core tests:** if Lower A delayed to Thursday and Lower B Saturday, explicit user review of adjacency. If only adjustable dumbbells remain, barbell/machine variants are invalid until independently replaced; their recorded loads cannot transfer as-is. A 60-minute flexible cap is an *estimate goal*, not a guarantee.

**Human verdict:** *Architecturally coherent, unqualified numerical workload/effort.*

## Blueprint C — Four available dates with preferred *rolling PPL* (cross-month)

**Synthetic schedule:** Tuesday, Thursday, Saturday, Sunday each week. **Sequence:** Push → Pull → Legs → repeat; sequence state advances **only when a scheduled session is actually chosen/completed by the user**, not because Sunday ended. Generic concepts, not a copied six-day program.

| Date | Original session *type*, only | Continuation state |
| --- | --- | --- |
| Tue 2026-10-20 | Push | Next Pull |
| Thu 2026-10-22 | Pull | Next Legs |
| Sat 2026-10-24 | Legs | Next Push |
| Sun 2026-10-25 | Push | Next Pull |
| Tue 2026-10-27 | Pull | Next Legs |
| Thu 2026-10-29 | Legs | Next Push |
| Sat 2026-10-31 | Push | Next Pull |
| Sun 2026-11-01 | Pull | Next Legs |

**Note:** These dates straddle the U.S. 2026 daylight-saving fall transition on **November 1**. Session identifiers and intended local dates must survive the offset change; never convert a late local Sunday to an unrelated “Monday workout.” No claim about UTC offsets or specific start/end times is needed to test ordering.

**Missed-session test:** If Saturday Oct 31 is missed, the user can choose to **carry** the still-pending Push session to the next available date, explicitly **skip** it and advance, or **reschedule** within their constraints. The system must display which choice changes the next session; it must not silently mark it performed or manufacture an extra fifth training date. Workload balance must be evaluated over several weeks, not just a named seven-day calendar cell.

**Muscle actions:** Push includes pressing/elbow-extension actions; Pull includes back/scapular action with elbow flexors secondary; Legs includes knee/hip/ankle actions. These are categories; not a hidden author-proprietary exercise table.

**Human verdict:** *Calendar logic ready for later isolated acceptance testing, movement-volume/effort authority pending.*

## Blueprint D — Three short sessions, adjustable dumbbells only, returning from interruption

**Synthetic context:** Monday/Wednesday/Friday, 30–35 minutes flexible, user confirms adjustable dumbbells and clear floor space only. The user has **not** yet established current strength, skill or recent tolerability. Personal use of other furnishings or machines is **not assumed**.

| Session | Feasible original action examples (no sets/rep instructions) | Missing/uncertain coverage |
| --- | --- | --- |
| D1 | Goblet-squat pattern; dumbbell floor press; standing split-stance row | No vertical cable pull; hinge and calf direct work could be deferred |
| D2 | Dumbbell hip hinge (only if proficient); unilateral split-squat pattern; controlled supported/floor-based pressing option if actually feasible | No claim that historical barbell lifts transfer to dumbbell loading |
| D3 | Knee-dominant squat variant; dumbbell elbow-flexion/shoulder action and a repeatable back-action movement | May be too much redundancy or too little back work; human reviewer must adjudicate |

**Re-entry:** first exposures establish skill, comfort and genuinely completed performance; do not infer an old personal record or require testing to absolute failure. A user can indicate insufficient confidence and receive a preview limited to feasible choices. This is **not** the author's Comeback source weeks or automatic return-to-training medical clearance.

**Time/selection failure:** a direct vertical pulling option is not secretly invented from equipment that is not there. If the user prioritizes that action, show missing equipment and a realistic substitution/goal tradeoff. Do not make an arm curl count as a validated vertical-back exercise.

**Human verdict:** *Partial draft awaiting confirmation of current ability and safe technique before a true training plan can be proposed.*
