## Status and field interpretation

**O** means owner-approved desired outcome/direction, including explicit corrections in this review; it does not accept a schema, threshold, algorithm or release. **P** means proposed idea/mechanism, including audit section 23 proposals and unaccepted security/operational mechanisms. GEN-009 additionally records explicit principle approval on 2026-09-28. Delivery/current columns are descriptive audited implementation status, separate from requirement approval.

For every row: **Verified** for the complete criterion = not yet established; **release Owner-accepted** = pending. Known evidence is a limited historical observation, not full qualification. No historic checkmark is copied into acceptance. Some components are implemented, while required correctness remains partial. All known audit observations resolve through [AUD-20260928](../evidence/README.md#audit-reference-and-migration-plan); artifacts remain outside Git. Missing evidence describes future qualification, not an existing run/test ID.

Applicable mode, rationale, milestone, controlling contract/ADR, responsible system/module, acceptance, current status, known evidence and missing evidence are recorded below. Milestones indicate proposed placement, not automatic release-blocker status. Block only violated controlling invariants/security prerequisites for an affected change; deferred ideas are not global release gates. Exact numeric training thresholds and new service targets remain proposed.
