# FERRAVIS working identity

Owner-selected working name: **FERRAVIS**. Positioning: **Strength, Engineered.**
This package changes public identity and the two requested interface defects.
It introduces no prescription, program, scientific-policy or deployment authority.

The original vector uses an angular F with a restrained deep-red upper bar on
graphite. It was drawn for this package from simple geometry; no existing legion
emblem or third-party fitness logo was used as a source. The compact symbol is
paired with a readable wordmark, rather than depending on the symbol for an
accessible product name. The existing approved interface, theme choices and
navigation structure remain the foundation.

The master is [ferravis-mark.svg](../../../apps/web/public/ferravis-mark.svg).
[generate-brand-icons.cjs](../../../apps/web/scripts/generate-brand-icons.cjs)
reproduces the 192/512px SVG and PNG exports, 512px maskable icon, 180px Apple
touch icon and 32px favicon through the existing Next.js sharp dependency.
The maskable export keeps the meaningful mark inside the central safe area.
These are web/PWA assets; native iPhone/Watch packaging is future work.

Public shell, login/setup, Home, appearance/settings help, metadata, manifest,
API title, password-reset message and default sender name use FERRAVIS. The
repository, database/schema, API routes, Docker identities, environment names,
browser storage/authentication keys, production domain and authored program
names keep their existing identifiers. An explicitly configured SMTP display
name still takes precedence over the new default; any production configuration
change belongs to the separately authorized release.

## Limited name review

On 2026-10-29, exact-name web queries for `"Ferravis" fitness training app` and
`"Ferravis" "S.C."` surfaced an existing
[Ferravis S.C. listing in Mexico](https://www.bizarchivo.mx/ferravis-s-c_2z).
Its directory classification is business services. Related archived directory
entries give differing categories, so they establish name use, not a verified
current business scope. The limited queries did not surface a direct fitness-app
match; this is not evidence of absence or exclusive rights.

FERRAVIS remains a working brand with **no commercial trademark-clearance
claim**. No live trademark-register, phonetic/similarity, international, domain
availability or comprehensive app-store clearance was performed. The
[USPTO clearance guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks)
describes broader federal/state/common-law and similar-mark searching. Commercial
release needs its own name/mark review in the intended markets.
