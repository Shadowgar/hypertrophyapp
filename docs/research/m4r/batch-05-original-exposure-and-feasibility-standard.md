# M4-R Batch 05 — Original exposure, split and time-budget standard (candidate v0.2)

**Date:** 2026-10-16. **Authority:** research proposal for future owner/human-expert review **only**. No generator, schema, model, trial policy, runtime config, edited Authored Plan, or numerical default is authorized. Read with [Batch 05 scientific appraisal](batch-05-volume-frequency-low-time-appraisal.md), [Batch 04 candidate design](batch-04-customized-program-design-standard.md), and [protocol](protocol.md).

## Central rule: maximize fit and the chance to perform high-quality work, not a fabricated hypertrophy score

For a *separately selected Customized* plan, construct a feasible training exposure schedule given **goal, recent training state, chosen dates, session-time budget, equipment actually present, technique constraints, movement preference, recoverability, and actual user review**. Split names are user-visible organization conventions. No hypertrophy ranking bonus for “Full Body,” “Upper/Lower” or “PPL” is scientifically admitted.

The product must distinguish:
- **Evidence that a smaller dose can produce some gains** from evidence that it maximizes expected gains for a particular trained individual.
- **Direct muscle exposure** from **secondary/indirect** work, without manufacturing a scientifically validated universal fraction.
- **Session nominal duration** from an enforceable **hard maximum**.
- **Planned** from **performed** sets; prescribed effort from **reported** effort; known user performance from unknown values.
- **Strength practice/progression** from muscle-size change; one is not a reliable real-time direct measurement of the other.
- **Authored-source facts** (author's PDF and workbook choices) from **independent Personalized/Customized claims** (our own decision process).

## Original exercise-exposure ledger: nonnumeric ontology, not “effective set” arithmetic

Each *originally selected* exercise archetype needs human-verified descriptive metadata:

| Field | Required interpretation |
| --- | --- |
| Movement and muscle action | Joint action and target region with explicit rationale; not an implied hypertrophy effect size |
| Primary/direct target | Muscles or regions intended to receive substantial directly targeted work; confidence/source |
| Secondary/indirect contribution | Other plausibly loaded muscles; **flagged separately**, never silently counted as a full or half direct set |
| Movement/equipment identity | Loaded variant, implements, support, ROM and load-basis semantics; avoid treating variants as automatically comparable |
| Time elements | Warmup, set preparation, working duration, rest, transition and equipment contention, each with uncertainty |
| Fatigue/skill context | Technical complexity and likely interference with nearby sessions; not an invented injury-risk percentage |
| Evidence-specific notes | Direct human hypertrophy comparison versus anatomical/motion inference versus author/user preference |
| User experience | Availability, dislike, discomfort, reliable performance and requested substitution reason |

**Minimal illustrative classification, for expert review only:** a horizontal press may be tagged as directly targeting pectoral muscles with triceps and anterior deltoid secondary; a horizontal pull as directly targeting relevant back regions with elbow flexors secondary. This does **not** assert that each row/press provides any stable coefficient for secondary growth. Region-level nuances from Batch 03 (hamstrings, calf, long-head triceps) may justify candidate alternatives only in their tested conditions, not a global best-exercise leaderboard.

**Reporting:** show **direct exposures, secondary exposures, and unclassified exposures in separate columns**, with actual completed exposure separated from planned. Where confidence is low or a movement spans multiple muscles, label uncertainty instead of turning it into a precise equivalence sum. Do not discard indirect involvement merely because it cannot be accurately quantified.

**Prohibited shortcut:** `direct sets + 0.5 × every indirect set = validated biological dose`. The 2026 meta-regression compared **model codings**, not participant-specific physiological constants. Any future weighting must be versioned, muscle/action-specific where warranted, prospectively checked and explicitly accepted, with unweighted alternatives visible.

## Practical program-construction decisions — qualitative, not approved prescriptions

1. **Assess feasible training opportunities.** Capture actual local calendar dates/timezone, session-cap type (hard vs flexible), available equipment, goals, training recency and restrictions. A missing essential input blocks activation; an explanatory preview may transparently mark the missing item.
2. **Respect explicit split preference.** If feasible, honor the named split. If infeasible, present a *choice* between changing the split, rolling the sequence across weeks, increasing sessions, extending time, or accepting reduced coverage. Do not silently alter the user's request.
3. **Map intended muscle actions.** Avoid repeatedly allocating near-identical movements that overload the same fatigue resources while leaving requested action/region coverage unaddressed. Treat compounds' secondary work qualitatively, not as nonexistent or fully interchangeable direct work.
4. **Select stable, achievable variants.** Favor user-tolerated, equipment-feasible choices that can be compared across completed exposures. Change for reasons (availability, preference, progress, target, discomfort), not an arbitrary weekly novelty timer. Do not copy the Essentials 2x/3x weeks or exercise lists.
5. **Distribute manageable work.** Multiple hard sets may matter for hypertrophy, but neither a minimum nor maximal weekly set dose has been personally validated here. Make the trade-off with a hard time limit visible, especially when lowering volume.
6. **Estimate actual time, conservatively.** Use warmup/setup/sets/rest/transition plus realistic uncertainty. Superset only independently workable noninterfering actions when equipment and layout permit. If the estimate breaches a hard cap, flag the plan as *unqualified* and offer transparent alternatives, never a false success label.
7. **Require consent and review.** Show session-by-session preview, rationale and uncertainties before activation. No source-owned program is mutated, converted or replaced.
8. **React to real histories.** Compare a completed set to prior genuinely comparable movement, ROM, loading basis and effort data. Preserve unknown RIR, missing load, interruptions, corrected sets and user overrides. A week boundary does not create completed work or an obligatory load increase.

## Original qualitative split test matrix

No copied proprietary exercise order, numerical workload prescription or default set schedule is presented below. Each archetype is an **acceptance test**, not a ready-to-train program.

| Scenario | Proposed original exposure design | Human reviewer must inspect |
| --- | --- | --- |
| **2 training dates/week, Full Body, hard 45 min** | Two compact, complementary whole-body movement-action exposures with repeatable anchors; prioritize user's major goals over pretending every region can be maximized | Are all exercises equipped? Are warmup/rest/transitions included? If work is reduced, is that disclosed rather than equated to a long session? |
| **3 days/week, choose for me** | Compare a rotating Full Body emphasis model, mixed Full Body/Upper/Lower, and an Upper/Lower roll based on preferred session lengths and actual dates | How does direct/secondary coverage differ over **successive actual weeks**, not just one idealized Monday–Sunday grid? Does each pattern fit the time cap? |
| **3 days/week, mandatory PPL** | Respect a nonrolling weekly PPL if feasible and expose its major-pattern distribution honestly; offer rolling sequence or Full Body alternative only with user choice | No statement that three-day PPL is intrinsically worse; no false claim that each region gets two identical weekly visits |
| **4 days/week, PPL preference** | A P–P–L rotation carried forward across calendar weeks when user selects a rolling program | Cross-week next-session pointer, missed-day choice, variable weekly pattern visits, no accidental restart |
| **4 days/week, Upper/Lower** | Distinct A/B upper and lower action emphases selected from original exercise ontology | Balanced distribution, adequate setup/recovery, no proprietary program reconstruction |
| **Any days, only adjustable dumbbells** | Equipment-feasible independently selected exercise actions | No implied machine/cable/barbell, impossible increments, or silent conversion of per-hand load into total load |
| **45 min requested but all candidate work estimates 60 min** | Explicit *time-infeasible* preview and prioritized, user-controlled options | Never label 60 as within a hard 45-minute cap, drop sets without disclosure, or promise equal hypertrophy after shortening |
| **Recently detrained user** | Conservative, adaptable re-entry proposal; actual tolerability/performance drives future change | No use of pre-break 1RM as present capability, no copied Comeback source block or forced failure target |

## Evidence-aware explanation standards

**Permitted:** “This exposure fits your available days and home equipment; rows also involve the elbow flexors, but the exact extra stimulus is uncertain.” / “We shortened optional work to fit your 45-minute cap. That makes training more manageable but may trade off some growth opportunity.” / “Two splits may produce similar average growth at equal volume; neither is guaranteed optimal for you.”

**Forbidden:** “This PPL split is 23% better.” / “Every pull supplies exactly 0.5 biceps sets.” / “One set gives maximal growth because low-dose studies found gains.” / “45-minute guaranteed” with 60-minute estimated completion. / “Improve every week or the workout is failing.” / “Same scientific outcome” without relevant equivalence evidence.

## Research acceptance before numerical dose rules

| Required decision | Status after Batch 05 |
| --- | --- |
| Base per-muscle set ranges by recent experience, region and equipment | **Blocked**: conditional literature synthesis, dose measurement and human review outstanding |
| Fractional assignment to indirect work | **Blocked**: published 2026 study's supplementary coding and direct validation not reviewed; no universal constant accepted |
| Default proximity-to-failure and fatigue modification | **Blocked**: direct RIR trials and experience-specific evidence unresolved |
| Inter-set rest or paired-set exact timing policy | **Blocked**: practical setup data and conditional outcome evidence unresolved |
| Original exercise ontology | **Candidate descriptive fields only**: needs independent expert checking and chosen-source citations |
| Schedule/time/activation integrity | **Candidate invariants**: require isolated acceptance tests in a separate future implementation phase |

## Stop/go decision

Batch 05 **adds a scientific caveat to the design standard, not approval of a generator**: the app should record uncertainty about secondary work and feasibility instead of hiding it under mathematically crisp but biologically unproven predictions. Keep Authored sources immutable. Next research batch should examine RIR, actual set effort, load and safe progression alongside direct/indirect set validation. A human coach and owner must accept bounded quantitative rules before a separate code design or implementation PR.
