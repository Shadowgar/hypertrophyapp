# Qualification issue template

Use for documentation or later explicitly authorized isolated qualification. Status: template, not a reported finding. Record:

- Summary, requirement/criterion IDs, mode and affected contract.
- Revision and dirty state; synthetic fixture/source/rule versions; environment and disposable target proof.
- Device/browser/version and exact steps; expected versus observed result.
- Impact and repeatability; actual decision/occurrence/slot/recommendation IDs when safely available.
- Sanitized evidence/artifact hash and access class; failure disposition (defect / obsolete expectation / fixture-environment / unresolved).
- Proposed bounded action, owner/reviewer and verification need; no invented fix/acceptance status.

Never include tokens/passwords/secret URLs, personal training data or proprietary source excerpts.
